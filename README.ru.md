# 🥤 BepisLoader

[English](README.md) · **Русский**

![BepisLoader Logo](BepisLogo.png)

**BepisLoader 2.3.4** — это нативное приложение для macOS для управления модами с поддержкой BepInEx и развивающейся архитектурой в сторону Reloaded-II. Оно устанавливает и настраивает моды для игр Windows, работающих через уровни совместимости, а также интегрируется со Steamac для виртуальных машин SteamOS. Программа разработана для работы с такими средами совместимости macOS, как **CrossOver**, **CrossOver Preview**, **Whisky**, **GameHub**, **Wineskin** и **Porting Kit**.

[Скачать BepisLoader 2.3.4](https://github.com/KiwiSingh/BepisLoader/releases/tag/v2.3.4) · [Все выпуски](https://github.com/KiwiSingh/BepisLoader/releases)

## 🚀 Основные возможности

| Возможность | Подробности |
|---|---|
| **Универсальное сканирование бутылок** | Автоматическое обнаружение бутылок в CrossOver (включая сборки Preview), Whisky, GameHub, Wineskin, Porting Kit и `~/.wine`. |
| **Поддержка внешних SSD** | Считывает `game_container_store.json` в GameHub и разрешает симлинки `dosdevices/` для обнаружения игр на любых внешних накопителях APFS/ExFAT. |
| **Поддержка Mono и IL2CPP** | Автоматически определяет движок Unity и скачивает нужную версию BepInEx: стабильную 5.x для Mono или передовую 6.x для IL2CPP. |
| **Патчинг конфигураций для каждого уровня** | Корректирует `cxbottle.conf` (CrossOver), `bottle.plist` (Whisky), `game-settings/<hash>.json` + реестр Wine (GameHub), `wine.cfg` (Porting Kit) и `Info.plist` (Wineskin) для автоматической загрузки модов при запуске. |
| **Прямое внедрение переменных окружения** | Для GameHub внедряет переменные `DOORSTOP_ENABLE`, `DOORSTOP_INVOKE_DLL_PATH` и пути среды Mono напрямую в словарь `environment` настроек JSON. |
| **Автоматическое снятие карантина** | Автоматически выполняет `xattr -rs com.apple.quarantine` для всех файлов BepInEx, предотвращая ошибки macOS «Разработчик не может быть проверен». |
| **Менеджер модов** | Установка плагинов `.dll` через диалог выбора файлов с поддержкой безопасности macOS для внешних накопителей и чтением метаданных `[BepInPlugin]`. |
| **Интеграция со Steamac** | Обнаружение игр SteamOS, проверка версий Proton и архитектуры Windows, развертывание BepInEx и проверка статуса установки через гостевой мост. |
| **Моды ассетов** | Универсальные команды **Install asset mod…** / **Disable asset mods** выбирают поддерживаемый адаптер. Первый адаптер объединяет замену ассетов Digimon Story Time Stranger и компилирует правки таблиц MBE при работе игры x64 под ARM64 Proton. |
| **Безопасная публикация** | Пакеты ассетов проверяются на отсутствие исполняемых файлов, неподдерживаемых зависимостей, симлинков и конфликтующих путей. Гостевая система проверяет сборку игры перед публикацией без перезаписи оригинальных файлов. |
| **Многоплатформенная архитектура** | Независимое от конкретного фреймворка управление играми и модами с инфраструктурой установки и зависимостей Reloaded-II. |

## Что нового? (v2.3.4)

Версия 2.3.4 представляет удобное переключение фокуса лаунчера и улучшенную интеграцию со Steamac:
- **Фокус окна Steamac**: при запуске игр через панель Steamac («Launch via Steamac») фокус окна теперь надежно передается лаунчеру FX Steam Launcher (Steamac) без повторного перехвата BepisLoader.
- **Повторное обнаружение префикса Proton**: добавлена функция **Rediscover Active Prefix** для принудительной синхронизации и обновления путей префикса Proton и активных сред выполнения.
- **Обновленная диагностика**: отображает статус готовности запуска с модами (`Modded launch: Available`) при подключении к мосту Steamac.
- **Быстрая навигация**: добавлена кнопка **🐸 Steamac** на главной боковой панели для быстрого перехода в панель управления Steamac.
- **Совместимость со Steamac 1.9**: рукопожатие гостевого моста теперь полностью совместимо со сборками Steamac 1.9 (`v1.9-kiwi.1` и оригинальным `fxgl/steamac`).

В версии 2.3.3 исправлена несовместимость структуры аудиобанков, когда моды с прямыми папками ACB в `Ryo/Digimon Story Time Stranger/` пропускались при сборке. Пути нормализованы до `Ryo/Digimon Story Time Stranger/bgm/`, что позволяет гостевому компилятору Steamac корректно собирать банки звуков.

В версии 2.3.2 добавлена нативная поддержка зависимостей для **Ryo Framework** (`DSTS.RyoFramework`, `Ryo.Reloaded`, `SharedScans.Reloaded`) и **DSTS Mod Tools** (`DSTS.ModTools`, `DSTS.ModLoader`).

В версии 2.3.1 добавлена автоматическая настройка ReShade и отдельный импортер модов ReShade (архивы ZIP/RAR/7z), увеличены лимиты профилей до 1 ГиБ и 128 МиБ на файл, внедрена сборка профилей на стороне гостя и повторное использование таблиц и музыки.

## 🛠 Установка и использование

1. **Скачивание**: Скачайте и распакуйте [BepisLoader-v2.3.4-macOS-universal.zip](https://github.com/KiwiSingh/BepisLoader/releases/download/v2.3.4/BepisLoader-v2.3.4-macOS-universal.zip).
2. **Выбор игры**: Приложение автоматически просканирует ваши бутылки. Если игра установлена на внешнем диске, используйте **«+ Add Game → From Mac / External Drive»**.
3. **Установка**: Нажмите **«Install BepisLoader»**. Программа загрузит нужную версию BepInEx, настроит реестр Wine и пропатчит конфигурационные файлы бутылки.
4. **Добавление модов**: Используйте **«+ Add Mod…»** для установки плагинов `.dll` в папку `BepInEx/plugins/` игры.
5. **Запуск**:
   - **ВАЖНО**: Запускайте игру **напрямую через ваш уровень совместимости** (CrossOver, Whisky, GameHub и т.д.).
   - **Игры IL2CPP**: При самом первом запуске может появиться черный экран на 10–30 секунд. **Не закрывайте игру.** В это время BepInEx генерирует сборки интеропа (прогресс можно отслеживать в `BepInEx/LogOutput.log`). Все последующие запуски будут быстрыми.

## 🏗 Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/KiwiSingh/BepisLoader
cd BepisLoader

# Сборка приложения .app с помощью скрипта
chmod +x build_app.sh inject_icon.sh
./build_app.sh

# Скрипт build_app.sh также автоматически выполняет inject_icon.sh.
# Для повторного внедрения иконки в существующий бандл:
./inject_icon.sh BepisLogo.png
```

Собранный `BepisLoader.app` будет находиться в папке `.build/release/`.

## 📋 Технические детали

- **Язык**: Swift 5.9 (нативный для macOS)
- **Минимальная ОС**: macOS 13.0 Ventura (macOS 26 Tahoe для пользователей GameHub)
- **Совместимость**: поддержка процессоров Intel и Apple Silicon (через Rosetta 2 для самих игр).
- **Метод внедрения**: проксирование `winhttp.dll` + `version.dll` через `WINEDLLOVERRIDES`.
- **Внедрение GameHub**: патчинг `game-settings/<hash>.json` в `settings.environment`. Использование абсолютных путей `Z:\` для всех переменных Doorstop для поддержки внешних дисков.
- **Области безопасности macOS**: использование `startAccessingSecurityScopedResource` при копировании модов с внешних накопителей.
