# BepisLoader 2.1.1 — Steamac interface cleanup

Removes developer diagnostic controls from the Steamac cockpit: local payload inspection, host release fetching, provenance discovery, recovery rehearsals, recovery-scope review/discovery, and guest recovery inventory collection.

The normal connection, game selection, asset-mod installation/disabling, framework installation, plugin installation and launch controls remain available. Existing validation and fail-closed installer behavior are unchanged.

Preserves asset filenames and bytes exactly. Removes hardcoded extension, texture-directory and DDS-header restrictions; raw `.img` assets and other filenames are accepted. Relative-path containment, collision, symlink and size checks remain.

Universal macOS build with the app icon injected by inject_icon.sh. Asset mods still require the matching Steamac guest capability and manual Steam Launch Options.
