# BepisLoader 2.2.0 — Asset Profiles and Batch Plugins

Development candidate; publication awaits bundle audit.

- First-class per-game asset profiles with multi-folder import, persistent guest state, individual enable/disable, removal, priority controls, and a full conflict/winner review.
- One stable asset folder for Steam Launch Options. Profile changes publish immutable combined snapshots and switch the guest pointer atomically; game restart required.
- Preserves raw asset filenames and bytes. Unsupported game builds, unsafe paths and unknown loader payloads remain blocked.
- Imports verified old single-package installs disabled for review. Update the old package-specific launch path once; subsequent changes keep the same setting.
- Multi-select BepInEx plugins in Steamac, whole-selection validation, no-overwrite preflight, checked publication and explicit partial-success reporting.

Requires Steamac Kiwi Build 6 with assetModProfilesV1. Steam can stay open; the game must be closed when applying a profile. Up to 64 mods and 256 MiB of referenced snapshots; combined assets are bounded to 4096 files, 64 MiB per file and 256 MiB total. Removing a package from a profile does not delete historical guest files. No automatic cleanup of retained snapshots is implemented.

The app is universal for macOS Intel/Apple Silicon and includes the injected icon. Publication remains separate from gameplay verification; enabling a package does not prove that all its assets are compatible with the game.
