# BepisLoader 2.1.0 — ARM64 SteamOS asset mods

BepisLoader now has game-agnostic **Install asset mod…** and **Disable asset mods** controls. Its first supported adapter handles loose DDS textures for the Windows x64 Digimon Story Time Stranger game under Proton on ARM64 SteamOS.

The FMC Eyes Green mod was tested in the live game: the native adapter logged replacement of `app_0/images/pch002a_E01_01.img` with the 43,852-byte DDS, and green eyes were confirmed by the user and observed in a gameplay close-up. This avoids the unresolved Reloaded-II/.NET hosting path.

## Required setup

- Steamac's guest agent must advertise `assetModInstallV1`; the [companion patch](https://github.com/KiwiSingh/steamac/releases/tag/v1.7.6-kiwi.5) adds that capability. The macOS app cannot add it to an older guest by itself. Installation fails closed on older bridges.
- The game must be closed during installation or disabling. **Steam can remain open.**
- **The user must manually set Steam Launch Options after installation.** Copy the exact line from BepisLoader's report into the game's Properties → Launch Options. It includes `BEPIS_MVGL_ASSET_ROOT`, the pinned `BEPIS_MVGL_EXE_SHA256`, `WINEDLLOVERRIDES='winmm=n,b'`, and `%command%`.
- Preserve existing launch settings when combining them. An existing Wine override may conflict. No automatic Steam shutdown, restart, or configuration rewrite is performed.
- Launch with Steam's Play button. Disable asset mods parks the checked adapter without deleting assets. Remove the BepisLoader setting from Launch Options when it is no longer needed.

## Scope

The adapter accepts `ModConfig.json` packages with raw assets under `dsts-loader/`. Filenames and bytes are preserved exactly; no extension, texture-directory or DDS-header restrictions are imposed. It supports one selected package per launch, not automatic merging/load order. Unknown code dependencies, executable mod payloads, symlinks, conflicting names and size-limit violations are rejected. The guest checks the exact game and loader hashes and publishes without replacing an existing destination. Assets are snapshotted per process; restart the game after changing them.

Supported game executable SHA-256: `ff9de825a543bf874cfb7e73ed951256d3ce4e8702957afa3b26ca6487a81688`. Other versions/games require a verified adapter. Full Reloaded-II managed-mod functionality is still under investigation; native texture replacement does not prove that path works.

Current Steamac recovery-scope planning, bounded inventory collection, host recovery rehearsals, provenance discovery, payload checks and transactional installer work are included. Existing runtime launch and framework safety gates remain fail closed.

## Packaging

The macOS app is built for Intel and Apple Silicon. `build_app.sh` invokes `inject_icon.sh`; `AppIcon.icns` and `CFBundleIconFile` are included. The icon script no longer copies the app into a hardcoded Downloads folder. Bundled native payloads include applicable GPL/MIT/BSD notices and corresponding source references; user mods and private backups are not redistributed.

## Validation

- Final universal macOS release build succeeded; bundled icon and adapter resources verified.
- Package validation passed 10 scenarios; installer policy and publication ordering checks passed.
- Six read-only launch-policy cases and eight existing Steamac regression checks passed.
- Companion guest bridge: 47 tests passed on each of Linux x64 and ARM64 ([CI run](https://github.com/KiwiSingh/steamac/actions/runs/38059166605)).
- Earlier native synthetic ARM64 Proton checks and 144 managed preparation tests passed. Live eye-texture replacement was confirmed separately in gameplay. These checks do not establish support for arbitrary managed mods.
